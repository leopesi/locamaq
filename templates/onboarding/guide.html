📚 Guia Passo a Passo

Siga os passos abaixo para configurar e usar o sistema corretamente.

Progresso do Setup 0 de 6 concluídos

O que fazer: Configure os dados que aparecerão nos comprovantes de locação.

📋 Instruções:

  1. No menu lateral, clique em ⚙️ Configurações
  2. Preencha o Nome da Empresa e CNPJ
  3. Adicione Telefone e Endereço
  4. Na seção "Cláusulas do Contrato", escreva:
    • Cláusulas gerais de responsabilidade
    • Condições de devolução
    • Termos de multa por atraso/dano
  5. Clique Salvar

💡 Dica: As cláusulas serão impressas automaticamente no comprovante PDF de cada locação.

Ir para Configurações →

O que fazer: Cadastre cada equipamento individualmente com seu código de patrimônio.

📋 Instruções:

  1. Vá em 🔧 Equipamentos → + Novo Equipamento
  2. Preencha o Código Patrimônio (ex: BET-001, AND-001)
  3. Informe o Nome (ex: Betoneira 400L)
  4. Selecione a Categoria (Andaime, Betoneira, Compactador, etc.)
  5. Defina os valores:
    • Diária: valor por dia
    • Semanal: valor por semana
    • Mensal: valor por mês
  6. Estado inicial: Disponível
  7. Clique Salvar

💡 Dica: Cada unidade física deve ter seu próprio cadastro. Se você tem 3 betoneiras iguais, cadastre BET-001, BET-002 e BET-003.

Cadastrar Equipamento →

O que fazer: Cadastre os clientes que vão alugar seus equipamentos.

📋 Instruções:

  1. Vá em 👥 Clientes → + Novo Cliente
  2. Escolha Pessoa Física ou Jurídica
  3. Preencha: Nome, CPF/CNPJ, RG
  4. Informe os telefones e WhatsApp (importante para envio de comprovantes)
  5. Preencha o Endereço completo
  6. Se souber, adicione o Endereço de Entrega/Obra
  7. Cadastre pelo menos 1 Referência (nome + telefone)
  8. Defina Limite de Crédito e Condição de Pagamento
  9. Clique Salvar

💡 Dica: O WhatsApp é usado para enviar comprovantes e promoções. Preencha no formato (34) 9 8826-7096.

Cadastrar Cliente →

O que fazer: Crie a locação selecionando cliente, equipamentos e período.

📋 Instruções:

  1. Vá em 📋 Locações → + Nova Locação
  2. Selecione o Cliente
  3. Escolha o Tipo de Período (Diária, Semanal ou Mensal)
  4. A Data de Início já vem preenchida com hoje
  5. Defina a Devolução Prevista
  6. Selecione a Forma de Pagamento (PIX, Dinheiro, Cartão, A Receber)
  7. Na seção Equipamentos, selecione os itens disponíveis
  8. Deixe "Valor Unit." em branco para usar o preço da tabela
  9. Preencha o Endereço de Entrega (aparecerá no mapa)
  10. Clique ✅ Criar Locação

⚠️ Importante: Após criar, você pode Imprimir o comprovante (PDF) e Enviar via WhatsApp na tela de detalhes da locação.

Criar Locação →

O que fazer: O sistema registra entradas automaticamente ao devolver locações. Registre saídas manualmente.

📋 Como funciona:

  • Entradas automáticas: Ao registrar a devolução de uma locação, o valor é lançado automaticamente como entrada
  • Saídas manuais: Registre despesas (combustível, manutenção, peças, etc.)
  • Filtro por período: Veja o saldo de qualquer período

Para registrar uma despesa:

  1. Vá em 💰 Financeiro → + Nova Transação
  2. Tipo: Saída
  3. Informe Valor, Descrição e Data
  4. Clique Salvar

💡 Dica: Para ver o resumo do mês, use o filtro de datas na tela do Financeiro.

Ver Financeiro →

O que fazer: Configure regras para receber alertas quando algo precisar de atenção.

📋 Instruções:

  1. Vá em 🔔 Notificações → ⚙️ Configurar Alertas
  2. Clique + Nova Regra
  3. Escolha o tipo de alerta:
    • Locação Atrasada — avisa quando cliente não devolveu
    • Pagamento Pendente — locações não pagas
    • Poucos Disponíveis — estoque baixo
    • Despesa Alta — gastos acima do limite
  4. Defina o Threshold (ex: 1 dia de atraso, 5 equipamentos mínimo)
  5. Escolha o Canal: Sistema (painel) ou WhatsApp do admin
  6. Clique Salvar

Para verificar alertas:

  • Clique em 🔍 Verificar Agora na tela de notificações
  • Os alertas aparecem no Dashboard e na tela de 🔔 Notificações

💡 Dica: Configure o WhatsApp em ⚙️ Configurações → WhatsApp para receber alertas críticos direto no celular.
